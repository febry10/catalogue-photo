# RAINCLOUD ONE — Catalogue Photo of an Impossible Gadget

A studio catalogue photograph of the **RAINCLOUD ONE**: a pocket rain cloud
that makes personal rain for exactly one houseplant. A glossy white
cloud-shaped unit on a chrome desk-lamp arm rains gently onto a single
terracotta pot — nothing else in the frame.

Entry for the make.fun bounty
[The Catalogue Photo of an Impossible Gadget](https://make.fun/bounty/the-catalogue-photo-of-an-2-20261121-0341).

## How it works

- `scene.html` — the self-contained SVG scene (cloud device, chrome arm,
  terracotta pot, rain), rendered once to `entry.png` at 1024×1024.
- `main.ts` — validates the photograph (PNG, 1024×1024, ≤ 1 MiB) and writes
  it to `/output/entry.png`, byte-identical on every run.
